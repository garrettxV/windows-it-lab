# Windows IT Lab (VirtualBox)

## Overview
This project simulates real-world IT support scenarios using a Windows virtual machine environment.

The goal is to build hands-on experience with:
- Operating system troubleshooting
- Networking issues
- User account management
- System configuration
- Help desk-style problem resolution

## Lab Environment
- VirtualBox
- Windows 10/11
- Simulated user issues and troubleshooting workflows

## Project Structure
- /setup → VM installation and configuration
- /scenarios → Real-world troubleshooting cases
- /assets → Screenshots and supporting files

## Purpose
This lab is designed to demonstrate practical IT support skills to potential employers.
